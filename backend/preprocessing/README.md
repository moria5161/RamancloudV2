`Raman_Preprocessing/raman_web/algorithms/despike.py`。


项目根目录的 `despike.py` 是原平台的命令行调用脚本；网站不调用该脚本，
也不修改其全局 CONFIG、不弹出 Matplotlib 窗口、不依赖原平台的目录。
`despike_core.py` 保留原件用于来源核对。2026-11-04 起，网站通过
`preprocessing/despike.py` 执行更保守的检测和修复，复用原算法的半高宽计算，
不再直接调用原件中按宽度删除整个候选区域的实现。
上传解析、原文件存储、处理方案、任务队列、图表和下载继续使用本站流程。

## 默认行为

- 默认顺序：裁剪（有需要时）→ 去鬼峰 → 降噪 → 基线校正。
- 去鬼峰只有一个算法，前端不提供算法选择器，可启用或跳过。
- 自动检测阈值 `threshold=None`，候选半高宽阈值 `fwhm_threshold=4.0` 个数据点。
- 以二阶差分 MAD 估计噪声，用峰显著度筛选候选，再检查半高宽；手动 `threshold` 表示显著度门槛。
- 自动修复还要求半高宽不超过 1.5 点，且两个直接相邻点相对于局部背景的高度均不超过峰高的 20%。有连续峰形支撑的候选保留。
- 只对通过条件的孤立采样点线性插值，不向左右扩展删除区域，波数轴和总点数不变。
- 高级设置可调整检测阈值和半高宽；空检测阈值表示自动，手动阈值须非负。
- 本站至少需要 8 个点。半高宽以数据点计，插值依据实际波数坐标，支持严格递增或递减的不等间距轴。
- 每个方案至多包含一个去鬼峰步骤，启用时必须在启用的降噪步骤之前。

支持正、负尖峰。检测结果是算法候选，可能包含真实窄峰，需检查预览。
本次保护了示例 `si.wxd` 中有连续峰形支撑的主峰，但单谱形状仍不能绝对区分欠采样的真实峰与孤立干扰。
网站记录候选数、修复数、保留数、改动点数、位置、原强度、修复后强度和半高宽，供图表标记、
分析历史、ZIP 导出和复现使用；位置明细最多保留前 256 处，统计包含全部检出。

单谱、批量光谱以及高光谱中的各条光谱独立调用同一个算法。
已有方案不自动添加或重排步骤；新建默认预处理方案采用上述顺序。
智能单谱页不再提供追加、删除或排序入口。旧处理策略的去鬼峰缓存会在新版本执行时失效，已有历史结果不覆盖。

## 验证

`backend/tests/test_despike.py` 检查正负尖峰、宽峰保留、无尖峰、批量独立性、
有连续峰形支撑的窄峰保留、实际波数插值、输入参数和顺序限制。
`backend/tests/despike_cases.py` 检查真实 HTTP 方案生成、预览、执行、跳过、
批量结果、原始数据不变、完整复现、旧策略缓存失效和双列下载精度。

V2 算法核对、修复原因和使用步骤见 [PREPROCESSING_ALGORITHMS.md](../../PREPROCESSING_ALGORITHMS.md)。
